# IT Security Handbook

## Passwords
Passwords must be at least 14 characters long and include upper case letters, lower case letters, numbers and symbols. Passwords expire every 180 days. Multi-factor authentication is mandatory for all accounts.

## Phishing
Report suspicious emails with the Report Phishing button in Outlook. Never enter credentials on a page opened from an email link. The security team responds to phishing reports within four business hours.

## Incident reporting
Security incidents must be reported to the Security Operations Center within one hour of discovery. Lost or stolen laptops must be reported immediately so the device can be remotely wiped.

## Software installation
Only software from the company software catalog may be installed. Requests for new software are reviewed by IT security within five business days.

## Data classification
Company data is classified as Public, Internal, Confidential or Highly Confidential. Highly Confidential data must be encrypted at rest and in transit and may only be shared with named recipients.
